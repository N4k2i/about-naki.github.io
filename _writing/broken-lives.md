## Overview

The project combines fiction with explicit progression mechanics. It uses a system-oriented structure so that character growth can be represented mechanically as well as narratively.

## System categories

- Levels
- Stats
- Skills
- Abilities
- Classes
- Roles
- Quests
- Objectives
- Unlocks
- Evolutions
- Territory
- Experience
- System notifications

## Story direction

The system is intended to create pressure and opportunity. A stronger character may unlock new options, but progression can also introduce new expectations, enemies, territory conflicts, or responsibilities.
