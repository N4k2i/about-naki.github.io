## Why this exists

Large story projects change.

Instead of leaving contradictory versions spread throughout the wiki, records use a simple canon model:

1. **Active canon** — currently valid.
2. **Draft / proposed** — not yet final.
3. **Superseded** — replaced by a newer decision.
4. **Non-canon** — intentionally excluded from the current continuity.
5. **Archived** — kept for historical context without being treated as current.

## Editing rule

The active record should describe what is true now.

The changelog can explain what changed and when, without forcing obsolete information into the main biography.
