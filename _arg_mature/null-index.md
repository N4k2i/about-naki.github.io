The first checksum failure showed twenty-six entries.

The current-cast bible has twenty-five.

For most of the ARG, the obvious question is:

**Who is twenty-six?**

The NULL Layer answers:

Wrong question.

The twenty-sixth slot has no stable name, pronouns, species, age, role, or voice.

It appears only when a system expects one more entity than the story contains.

The field is not a person.

It is a **gap given an ID**.

The first puzzle key is literal:

`WHO IS TWENTY SIX`

Remove spaces.

## 18+ NULL LAYER

The observer problem is allowed to become existential. If identity can occupy a structural slot, the player must confront
the possibility that some systems care more about **roles being filled** than about who fills them.

The archive does not claim that people are replaceable. It shows how easily systems can behave as though they are.
