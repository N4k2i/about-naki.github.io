The Mirror Layer reveals the first major hidden rule:

**Reality is not forgetting randomly. It is compressing.**

When several possible versions of an event cannot all fit the real world's continuity model,
reality selects one and weakens the rest.

The Character Bible does something similar on purpose:

Locked Canon overrides expansion.

Current continuity overrides superseded continuity.

The terrifying possibility is that the breach did not introduce fictional logic into reality.

It exposed that reality already uses a form of canon management.

The difference is that stories admit it.

The real world calls it memory.
