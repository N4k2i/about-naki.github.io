1. NOT ALL VERSIONS ARE LIES
2. CANON IS A MEMORY POLICY
3. THEY NEVER READ THE BIBLE
4. THE GAP REMEMBERS
5. WE WERE REAL TO EACH OTHER

Take the first letter of every word.

`NAVALC IAMP TNR TB TGR WWRT EO`

That looks wrong because word boundaries matter.

Now take only the **first word** of each phrase:

NOT  
CANON  
THEY  
THE  
WE

Initials:

`N C T T W`

Shift each letter forward by its layer number:

N+1 = O  
C+2 = E  
T+3 = W  
T+4 = X  
W+5 = B

Still nonsense.

The archive is teaching the final rule:

**Not every puzzle resolves by mechanical extraction.**

The correct final reconstruction is semantic:

> Versions can disagree without all being lies.  
> Canon decides what is remembered.  
> Witnesses recognize beyond description.  
> Gaps preserve structure.  
> Relationship makes reality meaningful.

The ARG does not provide one final password.

It provides a model.
